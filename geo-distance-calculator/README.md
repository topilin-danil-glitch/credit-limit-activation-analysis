Geo Distance Calculator

Пример работы: https://topilin-danil-glitch-credit-l-geo-distance-calculatorapp-utdicj.streamlit.app/

Веб-приложение(уже не факт)) для расчёта расстояния между двумя точками по их
географическим координатам. Реализована **формула гаверсинуса**
(great-circle distance) - устойчивый к малым расстояниям способ
вычисления дистанции по поверхности сферы.

---

Что умеет

- Ввод координат **двумя способами**:
  - числовые поля (широта/долгота с валидацией диапазонов);
  - строкой `55.753544, 37.621202` — в том числе в формате Яндекс Карт
    с десятичной запятой (`55,753544, 37,621202`).
- Расчёт расстояния по формуле гаверсинуса (радиус Земли 6 372 795 м).
- Проверка попадания в настраиваемый радиус (**«da» / «net»**).
- Визуализация обеих точек на интерактивной карте (`st.map`).
- Понятные сообщения об ошибках для некорректного ввода.

Формула

Расстояние по большому кругу между двумя точками на сфере:

d = 2R · asin( √( sin²(Δφ/2) + cosφ₁ · cosφ₂ · sin²(Δλ/2) ) )\

где
- `φ₁, φ₂` - широты точек (радианы),
- `λ₁, λ₂` - долготы точек (радианы),
- `Δφ = φ₂ - φ₁`, `Δλ = λ₂ − λ₁`,
- `R = 6 372 795 м` — средний радиус Земли,
- `d` - расстояние в метрах.

Почему гаверсинус

Наивное «евклидово» расстояние в градусах
`√(Δφ² + Δλ²) · 111111` работает только вблизи экватора и на малых
расстояниях: длина градуса долготы падает как `cos φ`. На широте Москвы
(≈ 55.75°) ошибка такой формулы достигает ~70%. Гаверсинус учитывает
сферичность Земли и остаётся точным на любых широтах и расстояниях.

Почему `asin`, а не `atan`

Формула через `atan` математически эквивалентна, но при `d → 0`
(совпадающие точки) даёт `0/0`. `asin(√a)` при `a → 0` устойчив — важно
для сценариев «точка внутри радиуса 200 м».

Быстрый старт

```
bash
git clone https://github.com/topilin-danil-glitch/geo-distance-calculator.git
cd geo-distance-calculator
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Откройте http://localhost:8501.

Тесты

bash
pytest -v

Покрыто:
- нулевое расстояние (совпадающие точки);
- эталонные пары (Красная площадь → Кремль ≈ 255 м; Москва → СПб ≈ 635 км);
- свойства (симметрия, 1° широты ≈ 111.2 км, 1° долготы на экваторе ≈ 111.3 км);
- устойчивость при `d = 1 м`;
- парсинг: точка/запятая, `;`, пробелы, отрицательные координаты,
  невалидные строки, выход за диапазоны.

Откуда брать координаты

Яндекс Карты → клик правой кнопкой по точке → «Что здесь?» →
внизу появится `55,753544, 37,621202` (запятая как десятичный разделитель
в русской локали — парсер это понимает).

Альтернатива: скопировать из URL карты `.../@55.753544,37.621202,17z` —
числа после `@` и есть координаты.

Google Maps: `55.753544, 37.621202` (десятичная точка).

Логика (`geo.py`) не зависит от Streamlit — её можно переиспользовать
в FastAPI/CLI/ноутбуке и тестировать без запуска UI.

Технологии

Python 3.10+, Streamlit, Pandas, Pytest. Без внешних API — всё считается
локально.
